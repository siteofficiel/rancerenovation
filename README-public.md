# 🏗️ RANCE RENOVATION — Site officiel

Site vitrine de **RANCE RENOVATION**, entreprise de travaux du bâtiment
certifiée **QUALIBAT** et **RGE** à Dinan (Côtes-d'Armor) :
maçonnerie, isolation, plâtrerie, menuiseries extérieures, revêtements
de sols, aménagement de salle de bain et de cuisine.

## 🌐 Mise en ligne (GitHub Pages)

1. Créez un dépôt **Public** nommé `rance-renovation-site` sur GitHub.
2. Glissez les 9 fichiers `*.html`, les favicons (`favicon*.png`,
   `favicon.ico`, `apple-touch-icon.png`) et le dossier `photos/`.
3. **Settings → Pages** → branch `main`, dossier `/ (root)` → **Save**.
4. Le site est en ligne en 1-2 minutes :
   `https://VOTRE-PSEUDO.github.io/rance-renovation-site/`

> 💡 Les pages sont autonomes (images intégrées) : elles fonctionnent
> aussi en local en double-cliquant sur `index.html`.

## 📰 Actualités

La page `actualites.html` récupère automatiquement les publications de la
page Facebook **Rance Rénovation** et les affiche comme des petits articles
(texte, photo, date). Les nouvelles publications apparaissent seules.
