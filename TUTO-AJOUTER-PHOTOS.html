1️⃣ Créer votre clé ImgBB

ImgBB héberge vos photos gratuitement. Sans clé, impossible de publier.

  1. Sur votre téléphone ou PC, ouvrez : https://imgbb.com
  2. Cliquez sur « Sign up » (S'inscrire) en haut à droite
  3. Créez un compte (email + mot de passe) et confirmez l'email reçu
  4. Connectez-vous, cliquez sur votre avatar (en haut à droite)
  5. Cliquez sur « API » (ou allez sur https://api.imgbb.com)
  6. Cliquez sur « Generate API key »
  7. Une clé s'affiche (30 caractères). Copiez-la et gardez-la.
💡 La clé ressemble à : a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6
Elle est gratuite et illimitée. Ne la partagez à personne.
⚠️ Une seule fois

2️⃣ Enregistrer la clé dans le panneau admin

Le panneau admin est caché dans votre site.

Sur téléphone 📱

  1. Ouvrez votre site en ligne sur le téléphone
  2. Appuyez sur le menu ☰ (en haut à droite)
  3. Allez dans « Mentions légales »
  4. Descendez tout en bas de la page
  5. Appuyez sur le petit ⚙ Admin

Sur ordinateur 💻

  1. Ouvrez nos-prestations.html (ou le site en ligne)
  2. Appuyez sur Ctrl + Maj + A

⚠️ Une seule fois

3️⃣ Mettre le site configuré en ligne

Remplacez simplement le fichier sur votre hébergeur.

Avec FileZilla (LWS, OVH…) 📁

  1. Ouvrez FileZilla et connectez-vous (identifiants FTP)
  2. À droite : ouvrez le dossier du site (souvent www/)
  3. Glissez le fichier téléchargé par-dessus l'ancien
  4. « Écraser ? » → Oui

Avec GitHub Pages 🐙

  1. Sur github.com, ouvrez votre dépôt
  2. Cliquez « Add file » → « Upload files »
  3. Glissez le fichier téléchargé par-dessus l'ancien (remplacement)
  4. Commit changes
✅ Une fois fait : c'est terminé pour toujours ! Vous n'aurez plus jamais besoin de remettre le site en ligne.
✅ À chaque fois — 30 secondes

4️⃣ Ajouter et publier une photo

Étape A — Ouvrir le panneau

Téléphone : ☰ Menu → Mentions légales → ⚙ Admin
PC : Ctrl + Maj + A → mot de passe rance2024

Étape B — Ajouter la photo

  1. Choisissez la galerie : Maçonnerie, Isolation, Menuiseries, Sols ou Peinture
  2. 📷 Prendre une photo (téléphone : la caméra s'ouvre directement) → ou cliquez sur la zone en pointillés pour choisir dans vos photos
  3. La photo apparaît avec le badge NOUVEAU

Étape C — Publier

  1. Cliquez sur « 📤 Publier mes photos »
  2. Patientez 2-3 secondes…
  3. Le badge passe à EN LIGNE ✓
☁️ Publication automatique

📤 Publier mes photos
✅ 2 photo(s) publiée(s) !

Étape D — Vérifier en ligne

  1. Ouvrez votre site → rechargez (F5 ou Ctrl+F5)
  2. Allez dans la galerie → la photo est là ! 🎉
⏱️ Si la photo n'apparaît pas tout de suite : attendez 2 à 5 minutes (le site garde un cache court) puis rechargez.
🆘 En cas de problème

5️⃣ Dépannage

« Clé invalide » → Re-vérifiez la clé (30 caractères, sans espaces). Régénérez-la sur imgbb.com → API → Generate key.
« Impossible de contacter ImgBB » → Vérifiez votre connexion Internet, réessayez.
« Aucune nouvelle photo à publier » → Ajoutez d'abord des photos (étape B), puis publiez.
La photo n'apparaît pas en ligne → 1) Avez-vous mis le « site configuré » en ligne (Partie 3) ? 2) Attendez 2-5 min. 3) Rechargez avec Ctrl+F5.
Je ne trouve pas le ⚙ Admin → Il est tout en bas de la page Mentions légales, en petit et gris. Descendez tout en bas !
